# Week 4 – Capstone Project & Deployment

This repository documents **Week 4 of the Full Stack Web Development (MERN)** learning track, focused on bringing a full-stack application together, testing it, documenting it, and deploying it.

## Topics Covered

- Advanced React components and API integration
- Application testing and debugging
- Cloud deployment using:
  - Vercel
  - Netlify
  - Render
  - MongoDB Atlas
- Project documentation and presentation

## Capstone Project Options

Choose one of the following project ideas:

### 1. E-Commerce Web Application
- Product listing
- User authentication
- Shopping cart
- Order management
- Admin dashboard for product control

### 2. Social Media Feed Application
- User registration
- Post creation
- Likes and comments
- Optional real-time updates using WebSockets

### 3. Project Management Dashboard
- Boards, lists, and task cards
- Drag-and-drop functionality
- Role-based access
- Data persistence

## Week 4 Practice Tasks

1. Integrate a React frontend with a Node.js backend.
2. Implement a login and signup flow.
3. Deploy the frontend on Vercel and the backend on Render.
4. Create a mini e-commerce application with products and a cart.
5. Submit the final project with its GitHub repository link.

## Deployment Platforms

| Component / Purpose | Platform |
|---|---|
| Frontend deployment | Vercel |
| Backend deployment | Render |
| Alternative frontend hosting | Netlify |
| Database hosting | MongoDB Atlas |

## Learning Outcome

By the end of Week 4, students are expected to demonstrate full-stack development proficiency and deploy their first production-level web application.

## Submission

Submit the completed final project along with its GitHub repository link, as specified in the practice set.
